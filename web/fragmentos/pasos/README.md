# Fragmento "Pasos"

Tres pasos numerados unidos por un camino punteado. En la landing Naturalista es "Prepárate en 3 pasos"; sirve para cualquier instrucción corta ("Cómo llegar", "Cómo adoptar un árbol").

## Qué se edita y cómo

| Qué | Cómo |
|---|---|
| Antetítulo y título | Clic y escribir |
| Título de cada paso | Clic y escribir. Corto: empieza con lo que hay que hacer ("Ajusta tu cámara") |
| Texto de cada paso | Clic y escribir (admite negritas y ligas). Dos o tres renglones |

Los números los pone la página: no hay que escribirlos.

## Qué no tocar

Son siempre tres pasos. Si se necesitan más o menos, pedirlo a quien mantiene el código (o usar el fragmento Sección con una lista).

## Para quien mantiene el código

Sin JavaScript. Necesita el Marco en la página.
